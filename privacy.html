Политика конфиденциальности приложения «FODMAP-дневник»

Дата вступления в силу: 25 ноября 2026 года

Настоящая политика описывает, как мобильное приложение «FODMAP-дневник» (далее — «Приложение») обращается с информацией пользователей.

1. Какие данные вводит пользователь

В Приложении пользователь может по своему желанию записывать: съеденные блюда и продукты, оценки самочувствия (вздутие, боль, газы, стул), текстовые заметки, этап диеты и результаты тестов переносимости продуктов, а также собственные продукты и блюда.

2. Где хранятся данные

Все данные хранятся только на устройстве пользователя, во внутренней памяти Приложения. Приложение не имеет серверной части, не требует регистрации и не отправляет введённые данные разработчику или третьим лицам.

3. Что Приложение не делает

  • не собирает персональные данные, имя, номер телефона, адрес электронной почты;
  • не определяет местоположение;
  • не использует рекламу, аналитику и трекеры;
  • не передаёт данные через интернет.

4. Резервные копии

Пользователь может по своей инициативе сохранить резервную копию записей в файл и восстановить данные из файла. Место сохранения файла выбирает сам пользователь. Разработчик не имеет доступа к этим файлам.

5. Удаление данных

Данные удаляются при удалении Приложения с устройства или при очистке данных Приложения в настройках Android. Восстановить удалённые данные можно только из резервной копии, сохранённой пользователем.

6. Медицинская оговорка

Приложение не является медицинским изделием, не ставит диагнозы и не назначает лечение. Информация о продуктах носит справочный характер. Перед изменением рациона рекомендуется проконсультироваться с врачом.

7. Изменения политики

При изменении политики новая редакция публикуется на этой странице с указанием даты.
